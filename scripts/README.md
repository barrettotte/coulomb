# Scripts

- [git-clone-all.sh](./git-clone-all.sh) - clone all public/private Github repos
- [git-status-all.sh](./git-status-all.sh) - show uncommitted changes across all repos in a directory
- [init.sh](./init.sh) - initial system setup (playbooks + distroboxes)
- [update.sh](./update.sh) - update host packages and all distroboxes
- [session/](./session/) - KDE session save/restore scripts for preserving window layouts across reboots
